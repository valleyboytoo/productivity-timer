## Project Description
For our final project, we built a GUI application using Python and Tkinter. Our idea is a "Productivity Timer" designed to help neurodiverse users (like people with ADHD) stay focused.

We followed the instructions to include socio-cultural aspects. We added features like:
* **Dyslexia/Visual Support:** Adjustable font sizes and a "Soft" theme (Old Book style) to reduce eye strain.
* **Languages:** You can switch the interface between English, Chinese, and Korean.
* **Background Sounds:** We added soothing sounds (Rain, Coffee, White Noise) to help users focus.
* **Motivation:** The app displays encouraging quotes when you finish a session.

## How to Run the Code
1. Make sure you have Python 3 installed.
2. Download the `Final_PY_SuXieJung.py` file.
3. **Important:** Download `rain.wav`, `coffee.wav`, and `white_noise.wav` and put them in the same folder as the code.
4. Open the terminal and type:
   `python Final_PY_SuXieJung.py`

## Features
* **Timer:** You can set custom Focus time and Break time.
* **Background Sounds:** You can choose Rain, Coffee, or White Noise to play while the timer runs.
* **Themes:** You can choose between Light, Dark, or Soft (Warm/Low Contrast) themes.
* **Languages:** Full support for English, Chinese, and Korean.
* **Font Size:** A slider to adjust text size for better readability.
* **Quotes:** Displays motivational quotes in the selected language after every session.

## Libraries Used
* tkinter (for the GUI)
* random (for selecting random quotes)
* winsound (for the beep and background sounds)
