## Project Description
For our final project, we built a GUI application using Python and Tkinter. Our idea is a "Productivity Timer" designed to help neurodiverse users (like people with ADHD) stay focused.

We followed the instructions to include socio-cultural aspects. We added features like:
* **Dyslexia Font:** A toggle to change the font to something easier to read.
* **Languages:** You can switch between English, Korean, and Chinese.
* **Background Sounds:** We added sounds like Rain and Coffee to help focus.
* **Gamification:** We added XP and Badges to make working more fun.

## How to Run the Code
1. Make sure you have Python 3 installed.
2. Download the `Final_PY_SuXieJung.py` file and the 3 sound files (`rain.wav`, `coffee.wav`, `white_noise.wav`).
3. Open the terminal and type:
   `python Final_PY_SuXieJung.py`

## Features
* **Timer:** You can set Focus time and Break time.
* **Visuals:** There is a circle that disappears as time goes down.
* **Background Sounds:** You can choose Rain, Coffee, or White Noise.
* **Settings:** You can change the theme (Soft or Playful) and font size.
* **Saving:** The app saves your XP and settings in a json file automatically.
* **Export:** You can save your session logs to a CSV file.

## Libraries Used
* tkinter (for the GUI)
* json (for saving data)
* csv (for exporting data)
* winsound (for the beep and background sounds)
